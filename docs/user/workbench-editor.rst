项目与画布操作
========================================

使用位置：浏览器工作台。进入前先确认当前实验是否已经部署。
未部署和已部署时都可以编辑设备、连线、地址与注释；已部署项目的网络变更需点击“应用拓扑”才会作用到容器。
修改前先保存需要保留的设备配置，清理与删除的区别见 :doc:`workbench-data`。

新建项目与重命名
----------------------------------------

工作台启动时显示空白画布，不会自动加载默认示例或打开已有实验。
点击顶部 **实验 → 新建项目**，或画布中央“新建项目”，在窗口填写名称并确认，
确认成功时空项目已经保存到当前服务器，再添加设备、连线并点击“保存项目”。这里的实验也称为项目。
名称支持中文，最长 80 个字符，首尾空白会去除，不能全部为空白；取消窗口会保留原项目。

点击顶部项目名称（带铅笔标记）打开“重命名项目”窗口。
已保存项目确认后立即保存新名称并更新列表；未保存项目改名后仍需点击“保存”写入后端。
已经部署的项目也可重命名，部署或清理过程中需等待操作完成。
改名失败会保留旧名称并显示错误；名称相同的项目仍通过不同 ID 区分。

改名不会复制实验或改变内部 ID，也不会改变设备配置目录、容器及终端连接。
重命名只保存名称，其他未保存的拓扑改动和属性草稿仍需按原流程保存。
有未保存修改时，切换实验或导入前先保存，或明确放弃当前草稿。

打开、保存、关闭与菜单栏
----------------------------------------

点击 **实验 → 打开项目**，按名称或 ID 搜索当前宿主机上已保存的实验。
选中条目后点击“打开项目”，也可双击条目；窗口显示设备数量和部署状态。
取消或打开失败会保留当前画布。刷新浏览器后需重新选择要打开的实验。

.. list-table:: 顶部菜单
   :header-rows: 1
   :widths: 20 80

   * - 菜单
     - 操作
   * - 实验
     - 新建、打开、保存、关闭项目、应用拓扑（已部署时）、重命名、导入/导出拓扑 JSON、删除当前实验。
   * - 视图
     - 显示或收起设备库、属性栏、底部面板；适应画布、查看部署日志或设备终端。
   * - 工具
     - 镜像管理、宿主机环境、刷新实验状态。

**保存项目** 写入当前连接服务器的数据目录，同时保存运行中受支持的 FRR 配置；
失败或不支持项会明确提示。部署后的网络改动仍需“应用拓扑”，保存不隐式重建设备。

选择 **实验 → 关闭项目** 会回收服务器终端与抓包，再清空工作台；项目记录与运行设备保留，
可以重新打开继续使用。关闭失败保留当前画布，存在未保存修改时先确认是否放弃。
清理设备和删除项目仍是独立操作。

菜单支持方向键切换和选择，Esc 关闭并返回菜单按钮，Tab 离开菜单。
菜单和对话框内的按键不会触发画布的删除或连线快捷键。

添加设备与查看画布
----------------------------------------

拖动左侧设备卡片到画布，或点击卡片添加设备。
拖动设备改变位置；拖动画布空白区域平移。
画布底部与右侧提供横向、纵向滚动条，拖动滚动条可查看拓扑的不同区域。
普通滚轮上下平移，``Shift`` ＋滚轮左右平移；按住 ``Ctrl`` 向上滚动放大、向下滚动缩小，
缩放以鼠标所在位置为中心，范围为 25%～250%。左上角的加减按钮和“适应画布”仍可使用。
滚动和缩放只改变查看位置，不产生未保存修改；重新加载项目后自动适应拓扑。

先点击左侧横向分类中的路由器、交换机、PC 或防火墙，进入后点击设备卡片或拖入画布。
子目录直接显示设备卡片，不设置搜索框；返回箭头回到分类首页。
需要导入镜像时使用顶部 **工具 → 镜像管理**。

画布中的设备使用圆形图标，名称显示在下方，不需要手动拉伸。
普通设备直径为 64 个画布单位，端口较多时自动稍微增大，保证接口可以点击。
旧文件中的矩形宽高仅作为兼容字段保留，不影响圆形显示。
长设备名在画布中缩略显示，鼠标悬浮可查看完整名称及设备类型。

连接端口与设置地址
----------------------------------------

点击一台设备上的空闲端口，再点击另一台设备的空闲端口，即可建立网线。
连线模式会显示接口名；端口悬浮提示包含对端信息。
一个端口只能连接一根网线。设备自身回环连线在第一版中不支持。

端口数量表示可用于接线的插槽。只有实际连接网线的端口才创建 veth 接口，
因此不能给尚未连接的端口配置地址。交换机端口为二层端口，不配置 IP。
默认网关必须位于设备某个已配置地址的子网内。

保存修改与部署后编辑
----------------------------------------

右侧“应用设置”修改当前画布草稿；顶部保存和导出也会应用正在编辑的设备或注释属性。
设备已部署时，可以继续添加、删除设备和网线，修改设备名称、镜像、端口、地址与启动配置，
也可以增删、编辑注释。

* **只改外观**：移动设备、自动对齐、切换连线优化、增删或修改注释后，点击“保存项目”。
  此操作保存展示内容，设备继续运行，现有终端连接保留。
* **改设备或接线**：先编辑画布，再点击“应用拓扑”。待应用时画布显示的是草稿，
  运行中的容器与网线仍按上一版拓扑工作；后端执行成功后，新拓扑才写入实验记录。
* **调整地址或端口**：应用时同步已有接口的地址、网关和连线；尚未接线的端口不会凭空创建接口，
  对应地址及没有活动接口可用的网关会在接线后应用。
* **修改设备名称、镜像、类型、模板、启动命令或 FRR 启动配置**：应用时重建受影响的设备；
  未变更的设备保持原容器。删除设备也会删除与它相连的网线。

草稿同时包含设备/接线修改和布局/注释变化时，“保存项目”暂时不可用；
点击“应用拓扑”会一并保存这些改动。

需要重建或删除设备前，先保存需要保留的运行配置。FRR 使用“保存设备配置”；
其他设备需按其自身方法备份。网络变更可能短暂中断通信，不能视为无中断升级。
“应用拓扑”开始后会关闭本实验的终端和抓包会话，完成后可重新打开。
纯布局保存不会关闭这些连接。

应用失败时查看部署日志。页面保留待应用草稿，后端保留上一版拓扑并尝试恢复已变更资源；
若状态异常，按提示清理设备再部署，不能假定网络已完整回滚。
未应用的草稿保存在当前页面，刷新或关闭前需完成应用或导出 JSON，避免丢失修改。
若提示基础拓扑已变化，先导出草稿，再重新打开最新实验并核对修改。
部署、应用拓扑、清理和保存期间暂时禁用编辑，滚动和缩放仍可使用。

删除项目
----------------------------------------

点击 **实验 → 删除当前实验**，可删除当前已保存或未保存的实验；
也可在未选中设备或网线时，从右侧实验属性中删除。
确认删除未保存项目后，清空当前画布和属性草稿，回到“空白画布”；
导入但未保存的草稿即使与已有实验 ID 相同，也不会删除已有实验文件。
删除已保存项目会移除其拓扑文件、设备配置目录、备份及列表项。已部署实验需先清理设备，才能删除。

快捷键
----------------------------------------

快捷键为 ``V`` 选择、``C`` 连线、``T`` 添加注释、``Delete`` 删除所选对象、``Esc`` 取消当前工具。

自动对齐和连线优化
----------------------------------------

项目名称与所有操作位于同一行：从左到右依次是项目名称、排版/连线/注释工具，以及保存项目、保存设备配置、清理与部署。
画布较窄时可在操作栏内横向滚动，或用 Tab 切换到需要的按钮；这些操作保持同一行。
顶部只需点击“自动对齐”，无需选择排列方式：

* 纵坐标接近的设备对齐到同一行，横坐标接近的设备对齐到同一列。
* 每组坐标差不超过 24 个画布单位，对齐到组内最上方或最左方的位置。
  例如两台设备纵坐标为 300 和 316，点击后都变为 300；相差较大的设备保留原位。
* 保留整体布局、当前缩放和显示位置；可能造成设备及名称区域重叠的移动会跳过。
  重复点击不会持续移动已经对齐的设备，没有可调整的位置时会显示提示。

点击“保存项目”保留新的位置。
对齐只改变设备位置，已有注释、设备地址、配置和网线端点保持不变。

“连线优化”默认开启。圆周端口位置会尽量朝向对端，优先使用较短的线路，
遇到中间设备时尝试折线绕行；拖动设备后自动重新计算。接口名称及实际 veth 关系保持不变。
关闭开关后使用固定端口位置和曲线，设置随项目保存。
此功能是画布排版，不是网络路由计算；复杂拓扑不保证所有线路无交叉或全局最短，
仍可移动设备来改善布局。设备已部署时也可使用对齐和优化开关，点击“保存项目”保留结果。

添加网段和实验注释
----------------------------------------

1. 点击顶部“添加注释”，或按 ``T``，再点击画布放置位置；按 ``Esc`` 可取消。
2. 在右侧填写说明，例如 ``10.10.1.0/24``、``OSPF Area 0``，支持换行。
3. 调整字号、文字颜色和背景，点击“应用注释”；拖动注释框改变位置。
4. 点击项目“保存”保留注释；导出 JSON 也包含注释内容和样式。
5. 删除时选中注释并按 ``Delete``，或点击右侧“删除注释”，不会删除设备或网线。

每个项目最多 100 条注释，每条最多 1000 字符，字号为 12～28；背景可选择透明。
注释文字不会自动配置设备 IP 地址。设备已部署时也可增删注释、修改内容与样式，
点击“保存项目”即可保留，不需要清理设备。
保存和导出会应用未提交的注释草稿；如果内容为空或格式无效，会提示错误并保留草稿。

调整侧边栏
----------------------------------------

左侧设备库和右侧属性栏都可以调整：

* 点击侧边栏右上角的箭头收起；收起后点击窄栏上的箭头或文字重新展开。
* 拖动侧边栏与画布之间的竖向分隔条调整宽度；右侧边界向左拖动会加宽属性栏。
* 双击分隔条恢复该侧默认宽度；分隔条获得焦点后可用左右方向键微调，Shift 加快调整，Home/End 调至最小/最大宽度。
* 左侧默认 240px，范围 200～420px；右侧默认 280px，范围 240～480px。
  窗口较窄时会进一步限制宽度，为中间工作区保留至少 460px。

宽度及收起状态保存在当前浏览器，刷新后恢复；缩小窗口不会丢失首选宽度。
收起属性栏不会丢失尚未应用的设备属性，调整布局不需要保存拓扑，设备部署后仍可操作。
页面目前适用于宽度至少 1000px 的桌面浏览器。
