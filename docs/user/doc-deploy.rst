阅读与部署文档
========================================

本页只说明如何打开或更新文档。文档预览服务的 8000 端口不运行实验后端；
启动工作台应按 :doc:`workbench-start` 操作。
从 :doc:`index` 按任务选择章节，左侧导航按首次使用、工作台操作、维护参考和旧版脚本分组。

如何快速找到内容
----------------------------------------

* **首页任务入口**：先选择安装、第一次实验、日常操作或故障排查。
* **左侧目录**：用于切换章节。长页在宽屏右侧显示“本页目录”，点击可跳到对应步骤；
  窄屏在正文开头显示页内导航，左侧菜单由顶部按钮展开。
* **搜索文档**：输入按钮名称、命令或报错关键词，例如“保存设备配置”“manifest.json”。
* **复制代码**：代码块右上角的“复制”只复制代码正文，保留换行，不含标题和按钮文字。
  浏览器不允许自动复制时会选中代码，请用 Ctrl+C 或 Command+C 手动复制。

教程开头说明操作位置和准备条件。代码块标题进一步区分 Linux 宿主机、客户端和设备终端；
先确认位置，再执行命令。表格中的管理命令是可选操作，按需要选择一项。
桌面与窄屏使用相同内容；本地打开 HTML 无需联网加载字体或排版资源。

HTML 与 PDF
----------------------------------------

构建后的 HTML 首页是 ``docs/html/index.html``，可直接在浏览器中打开。
两本 PDF 分别位于：

* ``docs/pdf/user/lwns-user.pdf``。
* ``docs/pdf/developer/lwns-dev.pdf``。

PDF 只有在成功执行 ``make pdf`` 或 ``make all`` 后才会生成。
构建环境和命令见开发指南“文档构建与版本发布”章节。

修改 ``.rst``、排版样式或脚本后，已有 HTML 不会自动变化，需要重新执行 ``make html``，
然后刷新浏览器。历史版本归档保持当时的内容，不会随当前文档一起更新。

Web 预览
----------------------------------------

从项目根目录执行::

  cd docs
  make serve

在运行服务的主机访问 ``http://127.0.0.1:8000/html/index.html``。
需要从其他机器访问时，可显式监听主机地址，例如::

  python3 -m http.server 8000 --bind 0.0.0.0

然后访问 ``http://<主机IP>:8000/html/index.html``。
服务根目录应为 ``docs/``，以便同时访问当前 HTML、PDF 和历史版本。

历史版本
----------------------------------------

左侧导航栏底部的“文档版本”可以切换已归档的版本。
目标版本没有当前页面时，选择器会打开该版本首页。
尚未创建归档时只显示当前构建。

归档入口是 ``docs/versions/index.html``。
发布完整版本列表时，应一起部署 ``html/``、``pdf/`` 和 ``versions/``；
仅交付单个版本时，明确说明未随包交付的其他版本不可访问。
